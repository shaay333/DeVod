DeVod is a decentralized video-sharing platform built using Ethereum and Polygon, featuring NFT minting and blockchain-based video transactions. It integrates smart contracts with OpenZeppelin’s ERC-721 standard for secure NFT operations and utilizes IPFS and NFT.Storage for decentralized file storage. The platform was developed with React.js and Material-UI, ensuring a responsive user interface, and deployed on IPFS for censorship resistance. Key technologies include Truffle, Ganache, MetaMask, and Web3.js for seamless smart contract deployment and interaction.
